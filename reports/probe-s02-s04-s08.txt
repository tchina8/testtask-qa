=== S-04 — повреждённое содержимое localStorage ===
строка не-JSON           → форма видна: true, записей в списке: 0, сообщение о пустом списке: true
                          ошибки в консоли: нет
объект вместо массива    → форма видна: true, записей в списке: 0, сообщение о пустом списке: true
                          ошибки в консоли: нет
массив без поля email    → форма видна: true, записей в списке: 1, сообщение о пустом списке: false
                          ошибки в консоли: нет
массив с null внутри     → форма видна: true, записей в списке: 0, сообщение о пустом списке: false
                          ошибки в консоли: pageerror: Cannot read properties of null (reading 'name')
обрезанный JSON          → форма видна: true, записей в списке: 0, сообщение о пустом списке: true
                          ошибки в консоли: pageerror: Cannot read properties of null (reading 'name')
