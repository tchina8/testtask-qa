## Известные проблемы

- **`node` не виден в PATH уже запущенных оболочек.** Процесс агента стартовал
  раньше установки Node. Перед любыми командами Node нужна строка обновления PATH
  из `AGENTS.md`. Симптом обманчив: выглядит как «Node не установлен».
- **Срок — 17.08.2026, 18:00.** Остаётся меньше суток на пункты 4–8. Порядок
  урезания при нехватке времени зафиксирован в `SPEC.md`: первой режется повторная
  проверка после фикса, последними — три баг-репорта и падающий автотест.
- **Часть II `AGENTS.md` и `SPEC.md` не прочитаны человеком глазами.** Оба писал
  агент по ответам пользователя; приёмка не выполнена. Риск известный: в файле
  правил может остаться то, чего в проекте нет.
- **Промпт-заказ не утверждён.** Пока он не принят, сессию-автора начинать нельзя.
- Приложения не существует, поэтому ни одна проверка из тест-плана ещё
  не выполнялась. HTTP 200 получен на пустом каталоге — это доказательство
  работоспособности стенда, а не приложения.
