## Известные проблемы

- **`node` не виден в PATH уже запущенных оболочек.** Перед любыми командами Node
  выполнять строку обновления PATH из `AGENTS.md`.
- **Встроенный браузер сессии наполовину нерабочий:** `screenshot` падает
  с `the Browser pane is not displayed`, а синтетические клики по ходу сессии
  перестали доходить до страницы (`submit` не срабатывает, программный
  `btn.click()` при этом работает). Всё, что зависит от настоящей мыши
  или картинки, гонять Playwright'ом.
- **Автотест один и покрывает только BUG-01.** После фикса BUG-02 и BUG-03
  проверять придётся руками либо дописывать тесты.
- **S-09 (значение вставлено из буфера) не проверен** — следствие того, что
  поля заполнялись скриптом. Дефекты вида «форма не видит вставленное значение»
  этим способом не ловятся.
